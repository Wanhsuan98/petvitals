# v1.2.0

Status: In Development（caregivers 已上線；notification 程式碼已完成，待執行 migration、設定 GitHub Secrets 並完成實機測試）

## Goals

讓照護不因單一人力而中斷：開放多照護者協作，並把主動提醒排程做進日常使用流程。

## Changes

- [x] 新增 `pet_caregivers` 資料表與 RLS 政策（owner OR accepted caregiver）
- [x] `find_user_id_by_email` 邀請查詢函式（security definer，僅 service_role 可呼叫）
- [x] `settings/caregivers` 邀請/移除管理頁
