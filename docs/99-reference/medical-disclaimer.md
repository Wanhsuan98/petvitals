# 法律免責條款 (Medical Disclaimer)

**免責聲明：** 本系統（PetVitals）僅作為飼主居家健康數據記錄、歷史趨勢可視化與日常照護之輔助工具，不具備獸醫臨床診斷功能，亦不構成任何醫療處方與治療建議。系統提供之 IRIS 分期標準與警戒提示僅供參考，毛孩之確切病情、輸液劑量與處方用藥，請務必遵循執業獸醫師之醫囑與指導。

## 顯示位置

- `/service#medical-disclaimer`（完整全文，公開頁面）
- 登入頁底部：簡短說明 + 連結到全文
- 設定頁「帳號」區塊：「服務說明與醫療免責聲明」連結
- 紀錄頁（`/records`）底部：警示與分期提示僅供參考 + 連結
- 回診報告頁尾：完整全文
