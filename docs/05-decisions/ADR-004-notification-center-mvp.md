# ADR-004: 通知中心第一版沿用邀請與裝置推播資料

Status: Accepted
Introduced: v1.2.0

## Context

首頁鈴鐺需要可操作的入口；既有系統已有協作邀請及排程推播，但沒有通知歷史或已讀資料。

## Decision

第一版提供 `/notifications`，整合待處理邀請、本裝置推播開關與提醒設定入口。角標計算本人待處理邀請，查看不改變其狀態。沿用既有資料與 RLS，不建立通知資料表。

## Consequences

- 沒有貓咪資料的登入者也能進入接受邀請，避免通知中心被建檔前置條件擋住。
- 角標表示待處理事項，不表示未讀訊息。清單於導覽、重新整理及接受邀請後更新，不宣稱即時更新。
- 裝置訂閱狀態不代表推播送達或照護完成；不將 `last_sent_on` 當作完整通知歷史。
- 提醒歷史、已讀、保存期限及推播送達追蹤留待後續版本另定資料契約與權限。
